# BrightNest Cleaning Co. Demo

A responsive cleaning-business website concept created for the Aruu Everlance Agency portfolio.

## Files
- `index.html` - page structure and content
- `styles.css` - responsive visual styling
- `script.js` - mobile navigation and demo quote-form confirmation

## Preview locally
Open `index.html` in a browser, or deploy this repository with Vercel using the default settings.

## Important demo notes
- BrightNest Cleaning Co. is a fictional portfolio concept, not a real cleaning company.
- The quote form is front-end only. It does not send, store, or process personal information.
- Photos load from Unsplash and Google Fonts are loaded from Google Fonts, so an internet connection is needed for those assets.
- Replace the demo brand, copy, imagery, and form handling before using this as a real client website.
